## Menjalankan aplikasi

Untuk aplikasi yang memakai JavaScript module, jalankan server lokal dari folder proyek, misalnya `python -m http.server 8000`, lalu buka `http://localhost:8000`. Detail untuk setiap tugas ada pada README foldernya.

**Catatan:** folder yang belum tercantum belum dibuat karena belum ada materi/tugasnya di repository.
