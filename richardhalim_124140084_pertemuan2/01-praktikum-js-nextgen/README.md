# Praktikum JavaScript Next Gen (ES6+)

**Richard Halim · 124140084 · Kelas RA**

Lab interaktif 12 demo JavaScript modern: const/let, arrow function, template literals, destructuring, spread/rest, map-filter-reduce, class, ES modules, optional chaining/nullish coalescing, Set/Map, Promise, dan async/await.

## Menjalankan
Buka terminal di folder ini dan jalankan python -m http.server 8000. Buka http://localhost:8000. Gunakan server lokal agar ES modules berjalan konsisten.

## Struktur
- index.html — halaman demo
- style.css — tampilan responsif
- main.js — rendering kartu dan event handler
- modules/data.js — contoh data, class, dan definisi 12 demo
- modules/utils.js — escape HTML dan format hasil

Demo memakai data contoh lokal; tidak mengirim data mahasiswa ke layanan eksternal.
