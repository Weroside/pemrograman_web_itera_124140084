Dokumentasi screenshot untuk laporan praktikum PAW Pertemuan 2

Simpan screenshot hasil pengujian nyata di folder screenshots/ setelah menjalankan aplikasi. Jangan menambahkan gambar mockup seolah-olah merupakan hasil eksekusi aplikasi.

Daftar tangkapan layar yang disarankan:
01-dashboard-utama.png — dashboard awal dan statistik.
02-form-tambah-tugas.png — dialog tambah/edit tugas.
03-filter-dan-pencarian.png — filter status, kategori, prioritas, dan pencarian.
04-catatan-agenda.png — panel catatan dan agenda.
05-penyimpanan-lokal.png — data tetap ada setelah refresh.
06-tampilan-mobile.png — layout pada lebar layar ponsel.
07-ekspor-json.png — berkas hasil ekspor JSON.

Petunjuk: jalankan python -m http.server 8000 dari folder dashboard, buka http://localhost:8000, lalu ambil screenshot dari browser. Berkas gambar sengaja tidak dibuat otomatis agar dokumentasi hanya memuat bukti yang benar-benar diambil dari aplikasi berjalan.
