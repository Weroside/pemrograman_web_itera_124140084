# Personal Dashboard — PAW Pertemuan 2

**Richard Halim · 124140084**

Dashboard responsif untuk mengelola tugas, catatan, agenda, dan progres belajar. Dibangun dengan HTML, CSS, JavaScript ES modules, class, dan localStorage.

## Fitur
- Tambah, edit, hapus, dan tandai tugas selesai.
- Cari tugas serta filter kategori, status, dan prioritas.
- Statistik tugas, progres selesai, serta hitungan terlambat.
- Catatan pribadi dan agenda sederhana.
- Persistensi browser, mode gelap, ekspor JSON, reset data.
- Widget cuaca Open-Meteo opsional; dashboard tetap berfungsi saat API gagal.
- Tes unit memakai Node.js built-in test runner.

## Menjalankan
Jalankan dari folder ini: python -m http.server 8000, kemudian buka http://localhost:8000. Memerlukan Node.js 18+ untuk npm test. Tidak ada dependency runtime tambahan. Data agenda awal adalah contoh, bukan jadwal resmi.
