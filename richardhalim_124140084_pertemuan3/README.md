# Pertemuan 3 — Aplikasi Manajemen Buku Pribadi (React)

**Richard Halim · NIM 124140084 · Kelas RA**

Tugas utama pertemuan ini adalah aplikasi React untuk mengelola buku pribadi, bukan halaman profil. Fitur: CRUD buku, pencarian judul/penulis, filter status baca, perubahan status, statistik, penyimpanan localStorage, Context API, dan React Router. File profil.html dan ilustrasi SVG yang sebelumnya dibuat tetap dipertahankan sebagai arsip.

## Menjalankan
Memerlukan Node.js 18+.

```bash
npm install
npm run dev
```
Buka alamat localhost dari Vite. Untuk build: `npm run build`.

Data contoh awal dapat diedit atau dihapus. Data disimpan di localStorage browser, bukan database server. Laman resmi Pertemuan 3 belum berhasil diakses pada sesi ini, jadi cocokkan kembali fitur dengan instruksi dosen sebelum pengumpulan.
